# 报告:M1 里程碑完成(2026-08-17)

## 1. 摘要

M1(内核核心原语)全部完成:陷阱/定时器 → 物理内存 buddy → Sv39 分页
→ 内核堆(slab)→ **线程调度(协作+抢占)→ 同步原语(Mutex/Condvar)**。
本轮为最后三项实现,含 bring-up 抓到的 3 个真实缺陷。

## 2. 本轮实现

### 2.1 协作上下文切换(riscv64.S)
- `context_switch(Context*, Context*)`:保存/恢复调用者保存寄存器
  (ra/sp/s0-s11);调用边界语义,t/a 按 ABI 可丢弃。

### 2.2 调度器(sched.rs)
- **线程**:独立内核栈(16KB,堆分配)+ 协作 Context + 全量陷阱帧
  (40 槽,抢占恢复用)。
- **协作切换**:yield 在调用边界经 Context 切换。
- **抢占切换**:定时器 ISR 内 `on_tick` —— 时间片到期(10 tick=100ms)
  且存在其他就绪线程时,把被中断线程的**全量陷阱帧**复制进其 TCB,
  返回下一线程帧指针;汇编恢复路径 sret 全量恢复(含 t/a)。
- **优先级**:2 级(HIGH/LOW),级内轮转;idle 最低。
- **退出/阻塞/唤醒**:exit / block_current / wake。

### 2.3 同步原语(sync.rs)
- **Mutex**(阻塞式):登记-再试协议防错过唤醒,释放唤醒队首。
- **Condvar**:wait 原子地"登记→释放锁→阻塞";notify_one/all。
- 语义依托调度器;IRQ 安全由关中断临界区保证。

## 3. Bring-up 抓到的真实缺陷(3 个)

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| S1 | 取指地址 0(scause=0xc) | 新线程**协作 Context 未初始化**(ra=0,ret 跳 0) | 初始 ctx.ra = thread_entry/idle_entry |
| S2 | 死锁(静默挂起) | 切换时**持有 SCHED 锁**,新线程入口再抢同锁 | 锁内完成状态变更+pick,锁外切换(中断关闭保原子) |
| S3 | — | 新线程首启时 SIE 状态不确定 | thread_entry 显式 irq_enable |

设计要点:调度器临界区全部 irq_save/restore(防 ISR 死锁,即
DEFERRED D11 的 IRQ 安全锁在调度路径落地)。

## 4. 自检覆盖

- 协作:2 线程各 50 次递增+yield,总数校验。
- 退出:线程返回后自动 exit。
- **抢占**:忙循环线程(不 yield,目标 100 万次,跨多个时间片)
  与主线程交替 —— 抢占失效则主线程饿死(超时即失败)。
- Mutex:2 线程各 1000 次锁内递增 → 2000。
- Condvar:生产者置 42 + notify,消费者 wait 校验。

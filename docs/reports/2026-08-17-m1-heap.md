# 报告:M1 内核堆(slab)实现 + bring-up 双 bug 修复(2026-08-17)

## 1. 摘要

实现内核堆(slab 小对象 + buddy 页大对象),`#[global_allocator]`
使 `Vec`/`Box` 在 no_std 内核中可用。bring-up 自检连续抓出并修复
**2 个真实 bug**(空指针访存、指针算术错误)。

## 2. 设计

- **slab 档**:8 档 2 的幂(16B..2KB),每页首部 `SlabHeader`
  (16B),空闲槽以首字 intrusive 链表挂在页头;槽对齐 = 档大小,
  满足 `align <= size` 小对象。
- **大对象**(> 2KB 或 align > 档):buddy 整块页,块基址记录在
  返回指针前 8 字节;高对齐(> 页)按"size + 8 + align"过量分配。
- **判别**:`SLAB_PAGE_CLASS` 静态表(页 → 档,0xFF = 非 slab),
  引导期写入、仅经裸指针访问。
- **同步**:SpinLock(主上下文;ISR 禁止,见 sync.rs 约束)。
- **OOM**:分配内部 panic(handle_alloc_error 稳定路径,无需 nightly)。

## 3. Bring-up 抓到并修复的 bug

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| B1 | 首次 slab 分配后 `ld 0x8(s0)` 空指针访存(`scause=0xd`,stval=0x8) | `slab_alloc` 第一分支调用 `new_slab` 后**丢弃返回值**,`classes[idx].head` 未挂载 | 第一分支显式 `self.classes[idx].head = nh` |
| B2 | 大对象释放失败(读取基址 = 0) | `ptr.sub(1)` 对 `*mut u8` 只减 **1 字节**(应减 8);读 0x8100c007 而非块基址 0x8100c000 | 改为 `(ptr as usize - 8) as *const usize` |

两处均已留注释(指针算术陷阱是经典错误)。

## 4. 自检覆盖

1. Vec 1000×u64(slab 多档 + 多次增长跨档)→ 校验长度与和
2. Box 64B(slab 单对象)
3. Box 4KB(> 阈值 → buddy 页路径)
4. 高对齐(align 8KB > 页 → 过量分配路径)
5. 100 次 Box<u32> 分配/释放(slab 复用防链表损坏)

## 6. 遗留

- slab 页永不归还 buddy(M1 规模可接受;页回收与 slab 释放入 M2)。
- 堆锁为 SpinLock:ISR 分配禁止(与 D3/D11 一致)。
- 高对齐路径按需过量分配,未做块内紧凑(未来可优化)。

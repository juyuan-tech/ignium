## 2. 发现明细

- 缺 M2 T1 新模块 `syscall.rs`;缺刚入库的 `.devcontainer/`;`scripts/` 未指向其 README。

### 2.2 ROADMAP 阶段 2 与现状脱节
- 「U/S 特权级 + 每进程地址空间」整行标 ✅,但**每进程地址空间(独立 satp)尚未实现**
  (T1 只完成 U/S 特权级,用户页仍映射在内核根表)—— 标记误导。
- 多核前置行遗漏 **D19(多核调度器)**,验收标准"调度器可分配线程到各核"实际依赖它。
- **缺少用户态异常恢复(D12)**:M3「服务崩溃恢复」的前提(用户进程故障应杀进程而非
  整机停机),M2 阶段没有对应任务行。
- IPC 行未标注对 **D22(woken 抢占)** 的依赖(优先级继承的前提)。

### 2.3 DEFERRED.md 结构松散
- 主表编号乱序(D1-D9 → D19-D24 → D10-D18),`待办`与`已实现`混排一张表;
- D10 已实现(alloc_pages_zeroed 已落地且 T1 已调用),仍标"待办"。

# 报告:外部审计第 12 轮处置(2026-08-17)

## 1. 摘要

外部 max 审计(`docs/audit-reports/20260817-105133-deepseek-v4-pro.md`):
4 HIGH / 4 MED / 3 LOW。本轮处置 4 项可立即消解项(低成本),
其余与 DEFERRED 注册表对账后维持登记(有触发条件)。

## 2. 发现与处置

### 2.1 已修复

| # | 级别 | 发现 | 修复 |
|---|---|---|---|
| HIGH-1 | HIGH | 分配器 `static mut` + 裸指针 `&mut` 无同步(潜在别名 UB) | 新建 **`sync.rs` SpinLock**,分配器单例改 `SpinLock` 包装,`with_allocator` 经锁取 `&mut`;`PAGE_META` 改普通 `static`(消除 static_mut) |
| HIGH-2 | HIGH | FDT 固定 1MB 预留:真机 FDT 可能更大 → 覆盖尾部 | **解析 FDT 头部**(magic 0xD00DFEED + totalsize 校验),按实际大小预留,非法回退 1MB |
| HIGH-3 | HIGH | 陷阱 handler 栈头寸 2KB 靠实测,格式化栈用可能超限 | 8KB(li+add 组合,`-8192` 超出 addi 立即数范围) |
| MED-4 | MED | deadline 算术在 overflow-checks 下可 panic | `wrapping_add`(boot 与 ISR 两处) |

### 2.2 维持登记(与 DEFERRED 对账)

- HIGH-4 板级常量 / MED-1 全局陷阱栈(D7)/ MED-2 守护页(D4)/
  MED-3 日志并发(D 契约,调度器时升级)/ LOW-1 build.rs 空格(cargo
  按单参数传递,不切分)/ LOW-2 CI 包名(Ubuntu 标准包)/
  LOW-3 README M0 字样(里程碑表历史行,进度已更新为 M1)。

### 2.3 开发期修正(实现过程中发现)

- `addi` 立即数上限 2047:陷阱头寸 -8192 需 `li+add`。
- 移除 mem.rs 未用导入;sync.rs 文档列表缩进(门禁捕获)。

## 3. 验证结果

- 门禁:dev+release / clippy / fmt / make test / **make test-smp** 全绿。
- 行为回归:单核 + SMP(2/4 核)引导、FDT 按实际大小预留、分配器经锁
  访问,自检与心跳全部正常。

## 4. 遗留

- D3 部分完成:SpinLock 已就位,IRQ 安全变体(保存/恢复 SIE)待调度器
  里程碑;ISR 内分配/锁调用禁止(文档约束)。

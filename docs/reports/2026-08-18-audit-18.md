# 审计 18 轮:全量代码审计 + 文档一致性(自审续)

## 摘要

C.4 轮自审(文档同步)后的**全量代码审计**:通读 kernel/src/ 全部 13 个
Rust 模块 + 3 个汇编文件 + linker.ld + docs/ 全部文档 + ROADMAP.md。
目标:确认无新功能缺陷、文档与代码一致、代码质量达到 M1 发布标准。

- **基础**:board.rs、sbi.rs、uart.rs、logger.rs、panic.rs、main.rs
- **链接脚本**:linker.ld
- **文档**:DESIGN.md、DEFERRED.md、ROADMAP.md、RVA23.md

### 说明

- **锁序**:已验证全部锁获取路径,顺序均为 `WAITERS→SCHED→HEAP` 或无环,
  无死锁风险。
- **双协议恢复**:`pick_next` 协作路径接受 `ctx_valid || frame_valid`,
  `do_switch` 按 `ctx_valid` 分发(context_switch/frame_restore);抢占路径
  (`on_tick`)只选 `frame_valid`。三个调用方(yield/block/exit)均预置 cur
  ctx_valid=true,兜底回 current 时原地返回。
- **ISR 零分配**:容量预留验证(MAX_THREADS=64,就绪队列/reaper/线程 Vec
  在 init 一次性预留);`on_tick` 仅做帧复制与队列操作,无分配。
- **丢失唤醒**:`wake` 无条件置 `woken`,`block_current` 三路径都已消费
  (Ready 早退分支 + woken 分支 + 醒来路径)。
- **Condvar::wait**:登记→释放互斥(唤醒互斥队首)→forget(guard)→block,
  锁序与唤醒语义正确。
- **文档**:DESIGN/DEFERRED/ROADMAP/RVA23 与 M1 现状一致,无过时陈述。
  ROADMAP.md 位于仓库根目录,AGENTS.md 引用已可解析。
- **unsafe**:`#[deny(unsafe_op_in_unsafe_fn)]` 生效,所有 `unsafe fn` 均有
  Safety 说明;内部 `unsafe {}` 块均有注释。

### 已确认无问题(重复审计,缩小范围)

- entry.S BSS 清零范围、boot_lock 仲裁、early_trap 停机
- riscv64.S trap_vector 嵌套检测、sscratch 恒置、frame_restore 协议
- riscv64.rs irq_save csrrci 原子性、timer ISR deadline 递增法
- main.rs 初始化顺序(irq_disable → sanitize → uart → traps → timer → mem
  → mmu → heap → sched → sync → irq_enable)
- sched.rs spawn 初始帧 SPIE|SPP 位、Thread 字段语义、yield 帧失效
- sync.rs SpinLock irq_save/restore 幂等、Mutex waiter 登记模式

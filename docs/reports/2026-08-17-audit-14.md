## 2. 修复明细

| # | 级别 | 发现 | 修复 |
|---|---|---|---|
| C1 | CRITICAL | **sched FRAME_WORDS=40 与陷阱帧 36 不符**:on_tick 用 `from_raw_parts(frame, 40)` 越界读 32 字节(UB,可能读入分配区元数据) | `FRAME_WORDS = arch::TRAP_FRAME_WORDS`(36,常量复用)+ 编译期断言;TRAP_FRAME_WORDS 转 pub |
| H1 | HIGH | **mem::init 信任无效 FDT 指针**:fdt=0 → 前 1MB 被误保留;随机值 → 任意块被排除,破坏刻蚀不变量 | fdt 合法性校验(非 0 / 4 对齐 / 在 RAM 内),无效 → 跳过保留(rs=re=0) |
| H2 | HIGH | **无条件 SSTC**:无 SSTC 平台 `csrw stimecmp` → 非法指令 → 停机,无法优雅回退 | 写读回一致性断言(启动即明确诊断);能力检测与 SBI 回退登记 **D17**(随 M1.5 FDT 解析落地) |
| M2 | MEDIUM | **page_alloc 加法溢出**:恶意 Layout(size+8+align-1 回绕) → 欠分配 → 堆破坏 | checked 算术,溢出 panic |
| L2 | LOW | **panic 水位在未知 sp 时回退 boot 栈**(误导诊断) | 未知 sp → 标记 UNKNOWN,不默认扫描 |

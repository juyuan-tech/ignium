# 报告:外部审计第 10 轮处置(2026-08-17)

## 2. 发现与处置明细

### 2.1 已修复

| # | 级别 | 发现 | 修复 |
|---|---|---|---|
| H1 | HIGH | `SATP_PPN_MASK = 0xF_FFFF_FFFF` 仅 **36 位**(Sv39 satp PPN 为 44 位);128MB 下不触发,大内存会截断根表地址 | 改为 `0xFFF_FFFF_FFFF`(44 位) |
| H2 | HIGH | `ensure_table` 不区分**叶子超页**与**表指针**:对超页覆盖区内做 4KB 映射会把超页数据当页表写(静默损坏) | 入口检查 `R/W/X` 位:叶子 → 返回 Err,调用方 fail-loudly(expect/panic) |
| M3 | MED | 早期引导陷阱窗口:init_traps 之前 `stvec` 为空,异常跳地址 0 | entry.S 安装 `early_trap` stub(关中断 + wfi 停机),`_start` 即指向 |
| L2 | LOW | extern 链接符号经**引用**取值(`&X as usize`),严格有效性下有疑义 | 全部改 `(&raw const X).addr()`(不形成引用)并去掉多余 unsafe 块:panic.rs ×4、riscv64.rs ×3、mem.rs ×1 |
| L1 | LOW | `__global_pointer$` 注释声称覆盖 .sbss,实际 ±2KB 不可达 | 注释诚实化(当前 Rust 裸机不生成 gp 相对访问,锚点仅预留) |
| I2 | INFO | `page_count()` 返回含补齐页的 padded 值,统计虚高 | 改返回 `real_count` |

### 2.2 核实后维持现状(已文档化,非新问题)

- **M1 日志 ISR 交错**:既有契约(ISR 零日志,见 logger.rs 模块注释);调度器里程碑引入锁。
- **M2 硬编码常量**:FDT 解析列入 M1.5。
- **L3 陷阱序言窗口**:中断关闭下不可达(仅同步异常、指令合法),已注释。
- **L4 定时器追赶**:deadline 单调递增,burst 自限(非自维持风暴),单调时钟的正确行为。
- **I1 孤儿段策略**:review 纪律(AGENTS.md 红线 4)。

## 2. 发现明细

### 2.1 外部审计(第 9 轮)

| # | 级别 | 发现 | 位置 | 影响 |
|---|---|---|---|---|
| H1 | HIGH | **FDT 保留区起点向上取整**:FDT 指针未页对齐时其所在页未受保护 | mem.rs init | 分配器可能覆盖 FDT 首页 |
| M1 | MED | **SBI 调用约定**:调用方须假定 a0-a7 全部被覆写,只声明 a0/a1 会让编译器活跃值被 ecall 破坏 | sbi.rs set_timer | 潜在寄存器破坏(当前编译器未中招,属未定义行为) |
| M2 | MED | 无保留区时 <16MB 尾部内存整段浪费 | mem.rs init | 内存利用率损失 |
| M3 | MED | boot 定时器失败 warn+挂死,不如明确失败 | riscv64.rs enable_timer | 故障可诊断性 |
| L2 | LOW | 陷阱向量头注释声称"可重入",实现为嵌套即停机 | riscv64.S | 文档与实现不符 |

### 2.2 开发期自发现(分页 bring-up)

| # | 级别 | 发现 | 位置 | 影响 |
|---|---|---|---|---|
| D1 | HIGH | **PMP 访问故障**:自检写入 `0x80000000`(OpenSBI 固件区,Domain0 Region02 为 M 模式独占)被 PMP 拒绝,`cause=7 store access fault` —— **映射本身正确**,是测试探针地址选错 | mmu.rs self_test | 启动必挂,误导定位 |
| D2 | LOW | `UART_MMIO_SIZE` 未使用、`error!` 未使用导入等编译噪音 | mmu.rs | 门禁失败 |

## 3. 修复明细

### 3.1 审计项修复

- **H1**:`fdt_start` 改为 `fdt / PAGE_SIZE * PAGE_SIZE`(向下取整,宁多护一页)。
- **M1**:`set_timer` 补 `lateout("a2")..("a7")` 全部 8 个参数寄存器。
- **M2**:无保留区路径尾部按 `ilog2(剩余)` 拆小阶块入链。
- **M3**:`enable_timer` 首次编程失败改为 `assert!`(panic)。
- **L2**:riscv64.S 头部注释改为「嵌套即停机;帧基于栈为未来 per-hart 应急栈预留」。

### 3.2 分页实现(`kernel/src/mmu.rs`,新建)

- **身份映射**(虚拟=物理):satp 切换后零重定位,代码/数据/栈地址不变。
- **RAM 128MB**:2MB 超页 ×64 条,RWX(U=0);M1.5 细化权限拆分。
- **UART MMIO**:4KB 映射(RW,无 X)。
- 页表页由 buddy(order-0)分配并清零,`ensure_table` 逐级按需创建。
- `enable()`:写 satp(Sv39+PPN)→ `sfence.vma`。
- 自检 4 项:satp 模式 / UART LSR 身份读取(MMIO 映射)/ 分页后 buddy 页写读回 / 根表 L2[0] 有效。

### 3.3 PMP 故障修复(D1)

自检探针从 `0x80000000`(OpenSBI 固件区,PMP 禁止 S 访问)改为:
- UART LSR 读取(验证 MMIO 身份映射)
- buddy 分配页写读回(验证 RAM RW 映射 + 分页后分配器仍可用)

**教训**:调试时用 QEMU `-d int` 抓到 `cause=7`(访问故障)而非 `cause=15`(页故障),区分"翻译失败"与"物理访问被拒"是定位关键。

## 5. 遗留风险与后续

| 项 | 说明 | 计划 |
|---|---|---|
| RAM 整体 RWX | 权限过宽(含 OpenSBI 区映射,但 PMP 仍兜底) | M1.5:镜像按 代码RX/数据RW 拆分 |
| 无 unmap/权限切换 API | mmu 仅提供 map;用户态需要 `arch_mmu_unmap` | M2 用户态前补齐 |
| FDT 固定预留 1MB | 未按实际大小 | M1.5 解析 FDT 后按大小 |
| 陷阱栈/引导栈无守护页 | 栈溢出仍可写入镜像上方区域 | M1.5 引入守卫页 |
| 无页表缓存(TLB 管理) | 仅 boot 一次性建表 | M2 增加 flush 接口 |
| allocator 非并发安全 | 单核假设 | 调度器出现后加锁 |

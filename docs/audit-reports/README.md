# 外部 AI 审计归档(External AI Audit Archive)

本目录保存**外部 AI 审计的原始转储**(`<时间戳>-<模型>.md`),是
`docs/reports/` 下各「审计 N 轮处置」报告的输入材料,属历史记录。

## 处置说明

- **原始转储不修改、不删除** —— 它们是处置结论的证据链,随仓库长期保留。
- 每轮转储的**处置结论**见 `docs/reports/2026-08-17-audit-10.md` 等对应报告
  (被处置的轮次、已修复项、登记进 `docs/DEFERRED.md` 的延后项)。
- 已知问题:转储包含大段源码摘录与对话式往返,单份体积大;阅读时优先看
  「发现明细」与「严重级别」表格,不必通读。

## 触发纪律

- **不再自动运行外部 AI 审计**(`scripts/ai_audit.py` 会把源码外发;密钥不入库)。
  本目录仅作历史留档。
- 若未来恢复外部审计:新转储存入本目录,处置结论写入 `docs/reports/` 对应报告,
  并同步更新 `docs/reports/README.md` 索引与 `docs/DEFERRED.md`。
